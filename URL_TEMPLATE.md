# Шаблон адреса для парсинга

## Формат

```
https://forum.awd.ru/viewtopic.php?t={id}
```

## Параметры

| Параметр | Назначение | Диапазон |
|---|---|---|
| `t` | Идентификатор темы форума | от `0` до `500000` (по умолчанию, задаётся в `parser_config.t_from` / `parser_config.t_to`) |

`{id}` подставляется целым числом без ведущих нулей.

## Примеры

- `https://forum.awd.ru/viewtopic.php?t=441019` — тема «Малоярославец. Май 2026. Город белый, город голубой»
- `https://forum.awd.ru/viewtopic.php?t=1` — несуществующая тема, отвечает HTTP 404

## Хранение

- База шаблона без подстановки: колонка `parser_config.base_url` (например, `https://forum.awd.ru/viewtopic.php?t=`); сервис склеивает её с текущим `id`
- Готовая ссылка сохраняется в `topic.source_url` и собирается обратно в `{base_url}{id}` при каждом проходе

## Ответы сервера

| Ответ | Обработка |
|---|---|
| HTTP 200 | Парсинг и upsert в БД |
| HTTP 404 | Считается `not_found`, пропуск без ошибки |
| HTTP 429 / 5xx | Повторные попытки с нарастающей задержкой, затем `failed` |
| 200 без темы («вы должны быть авторизованы») | Считается `login_required`, пропуск без ошибки |
